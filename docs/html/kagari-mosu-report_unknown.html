残る障壁

corelib/saori_basic/init.lua が saori_universal.native を require する段階で停止する。配布 NAR にあるのは Windows DLL。kotori 上流（確認 revision f161ffc62a642b67602ffd3bc42097e3885a2b5f）には native.so と fh/init.so もあるが、file でいずれも Linux x86-64 ELF と確認した。この調査範囲では対応するネイティブ実装のソースは見つかっていない。macOS で使用可能な正規実装またはソースを確保し、ABIとライセンスを確認して移植する必要がある。

fh も process から要求されるため次の候補。後段には lanes/SSL 等の依存が残る可能性があり、現在の1件を解消すれば完全対応するとは断定していない。ゴーストの Lua を書き換えて require を回避する方法は採用していない。
