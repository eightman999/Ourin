cursor-engines / P1 #101 委譲報告

作業日: 2026-10-25 (JST)
担当: cursor-engines (Composer)
Issue: #101（KAWARI/KAGARI 実エンジン + 互換マトリクス基盤）

結論

  • KAWARI: 上流 POSIX SHIORI（ukagaka-long + loadu）を Ourin の既存 NativeShioriModule でロード可能。Windows *.dll 名から同梱 libkawari_shiori.dylib へ解決する BundledShioriEngine を追加（親ビルド済み 8098dfb）。
  • KAGARI: engines/kagari/build.sh で Lua 5.4.4 + sol2 3.2.2 を task-local 取得・ビルドし、libkagari.dylib + 同梱 liblua.5.4.dylib（@loader_path）を arm64 でビルド成功。POSIX instance-ID ABI + load 失敗時 -1 パッチ適用済み。
  • 実ゴースト『もす』: 一時展開で kagari_load まで進行。socket.core は luasocket v3.1.0 の macOS ビルドで解決。続きは lua-utf8 / luachild / iconv / saori_caller 等 Windows 同梱 DLL の macOS ネイティブ未整備で kagari_load -> -1（ログは verify_kagari_mosu.py 出力）。
