Ourin（桜鈴）{{VERSION}} はじめにお読みください
================================================

Ourin は macOS で動く伺か（ukagaka）ベースウェアです。
SSP 向けに作られたゴースト・シェル・バルーン・プラグインを、Mac でそのまま動かすことを目指しています。

このパッケージの中身
--------------------
- Ourin Installer.app … Ourin 専用のインストーラー（おすすめ）
- Ourin.app            … アプリ本体（インストーラーを使わず手動で入れる場合）
- ライセンス/          … Ourin と同梱ソフトウェアのライセンス

どちらも Apple の Developer ID で署名し、Apple の公証を通しています（Apple シリコン／Intel 両対応）。

動作環境
--------
- macOS 13.0 (Ventura) 以降

インストール
------------
1. 「Ourin Installer.app」を開きます。
   初回は「インターネットからダウンロードされたアプリケーションです」と表示されるので「開く」を選びます。
2. 画面の案内に従うと、Ourin.app が「アプリケーション」フォルダに入ります。
   - Wine／CrossOver／Whisky で SSP を使っていた場合は、ゴーストとバルーンを Ourin にコピーできます（SSP 側のデータは変更しません）。
   - 最初に起動するゴーストを選べます。手元の .nar を一緒に入れることもできます。
3. 手動で入れる場合は、Ourin.app を「アプリケーション」フォルダへドラッグしてから起動してください。

ゴーストの追加
--------------
- .nar ファイルを Ourin のキャラクターへドラッグ＆ドロップするか、メニューバーの Ourin から「NARを読み込む...」を選びます。
- データは「書類」フォルダの Ourin（~/Documents/Ourin）に保存されます。

アップデート
------------
- Ourin は 1 日 1 回、新しい版を自動で確認します。
  新しい版があると案内が出るので「アップデートして再起動」を選んでください。
  ダウンロードした版は、Ourin と同じ開発者の署名であることを確かめてから入れ替えます。
- 手動で確認するときは、メニューバーの Ourin →「アップデートを確認...」を選びます。
- 自動確認は、設定 →「自動アップデート確認」でオフにできます。
- BOOTH で購入された方は、BOOTH のダウンロードページからも最新版を入手できます。

同梱ゴーストについて
--------------------
- 標準ゴースト「Sakura and Rinne」（さくら・りんね）を同梱しています。
- 「エミリー」などの他のゴーストは同梱していません。お好みのゴーストを各配布元から入手してください。

プラグインについて
------------------
- SSP 向けプラグインのうち、本体が YAYA（yaya.dll）や KAGARI（kagari.dll）のものは、Ourin がそのまま動かします。
- Windows 専用の機能（Windows のアプリとの連携など）を使うプラグインは動きません。

注意
----
- ベータ版です。大切なゴーストのデータはバックアップを取ってからお使いください。
- すべてのゴースト・プラグインの動作を保証するものではありません。

アンインストール
----------------
- 「アプリケーション」フォルダの Ourin.app をゴミ箱へ移します。
- ゴーストなどのデータも消す場合は、~/Documents/Ourin を削除します（元に戻せないので注意してください）。
