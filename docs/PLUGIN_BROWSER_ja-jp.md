# プラグインを探す・管理

アプリメニュー、メニューバーの「プラグイン」、ゴーストの右クリックメニューから「プラグインを探す・管理…」を開く。設定画面からも同じ機能を使える。

- **探す**: [Ourinの対応版配布ページ](https://furinlab.com/ourin/docs/library/compatibility-plugin-ports/ja/)で管理する [packages.json](https://furinlab.com/ourin/downloads/plugins/packages.json) を取得し、名前・ID・検証範囲・制限で検索する。サイトに作者情報があれば作者も検索対象になる。再配布対象の `packages` だけを掲載し、`withheld` は除外する。「Ourin版ZIPを入手」は既定ブラウザでOurinサイトの対応版ZIPを開く。原作者の配布元へのリンクも併記する。各項目の検証範囲・制限を表示し、掲載を全機能の動作保証とは扱わない。

- **導入済み**: 名前・ID・作者で検索し、状態の確認やFinderでの表示ができる。読み込み済みRegistryに加えてプラグイン配置先を読み取り専用で走査するため、新規インストール直後の未読込パッケージも表示する。「更新」は一覧を取り直し、プラグインの実行・再読み込みは行わない。
- **導入**: Ourin版ZIPは展開し、同梱READMEの指示に従って配置する。「配置先フォルダを開く」で使用中の `plugin` フォルダを開ける。NAR形式のプラグインは「NARから導入…」で既存のNARインストール経路へ渡す。配布ZIPをNARとしてインストールしない。導入後は一覧を更新し、未読込表示の場合はOurinを再起動して状態を確認する。

配布情報の取得に失敗した場合は理由と再試行ボタンを表示する。取得は画面表示時と「探す」の更新操作時だけ行い、検索文字列を外部へ送信しない。
