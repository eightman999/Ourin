## 5. リスク

- `OurinTests`/`OurinUITests` の deployment target を 15.5→13.0 に下げた。
  Swift Testing フレームワークの下限を下回ると test ターゲットのコンパイル
  で失敗し得る (実害なしと判断するが親 build で確認)。
- shared scheme 追加で testables = OurinTests + OurinUITests が `xcodebuild
  test` で両方実行される。UITests が CI 上で権限/不安定さを持つ場合
  test ジョブが flaky 化し得る → その場合 scheme 側で UITests を
  `skipped="YES"` にするフォールバックを提案。
- Rosetta x86_64 leg は未検証のため advisory (continue-on-error) 扱い。
- workflow は未実行のため YAML/パス (DerivedData 配下) の実地確認が必要。
