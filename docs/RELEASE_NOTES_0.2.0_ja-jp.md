## 変更内容

SHIORIエンジンを `.plugin` で追加する機能を用意しました。「プラグインを探す・管理…」→「SHIORIエンジン」から導入し、必要ならゴーストへの割当や自動選択への復帰を行えます。割当はOurin側へ保存し、元の辞書や `descript.txt` を書き換えません。

- **公式YAYA Tc607-2**: 公式POSIX実装を使う `yaya.plugin` を追加。複数ゴーストの辞書・変数を独立して扱います。
- **AYA5互換**: 同じ公式YAYAを使う `aya.plugin` で、AYA5の設定名やDLL名へ対応。原本AYA5やAYA1〜4の移植ではありません。
- **なし栞**: 許諾のある公式mainの1.0.4-alpha系をmacOSへ移植した `nashi.plugin` を追加。ゴーストごとにSHIOLINK子プロセスを分け、辞書・変数と保存を分離します。
- **エンジン選択**: 導入済みプラグインを通常の起動・再ロードへ接続。曖昧な候補や失効した明示割当を、別の内蔵VMの成功で隠さないようにしました。ゴースト側の明示的なmacOSモジュールやOurin用設定も維持します。
- **文字コード**: ゴーストのencoding指定を優先し、未指定の場合だけプラグインの既定値を使用。AYA5互換のCP932文字も、元の設定を書き換えずに往復します。

### 表示・導入・操作の改善

- **バルーンの選択**: ゴーストごとの選択を保存し、再起動後に復元します。
- **キャラクターごとの表示切替**: 同じサーフェス別名がキャラクターごとに異なる絵を指す場合、対象キャラクターの定義で解決します。
- **着せ替え**: キャラクター切替やアニメーション停止の後も、着せ替えレイヤーを保持するよう改善しました。
- **NARの取り込み**: Windows形式のパス区切りや、空ディレクトリ情報を含むNARのパス処理を修正しました。
- **ゴーストへ渡す状態情報**: 表示中のバルーン・選択肢・入力ダイアログ・最小化など、実際の画面状態をSHIORIのStatusへ反映します。
- **追加画面の翻訳**: プラグイン管理・SHIORIエンジン画面の表示を、日本語・英語・簡体字・繁体字・韓国語で用意しました。
- **動作環境の統一**: 本体・XPC・YAYAヘルパーの最低OS指定をmacOS 13.0へ揃え、ほかの同梱バイナリも13.0上で読み込める最低OS指定であることを確認しました。
- **安定性**: バックグラウンド処理からアプリの状態を参照する際も、画面の処理と同期するようにしました。

YAYA・里々・KAGARIの既存内蔵経路、自動アップデート、公開済みの互換性修正を維持して統合しました。

## 本体と追加SHIORIの配布

本体・インストーラーは既存の配布形式を維持します。BOOTHの無料版0円・応援版300円は、配布ファイルと機能が共通です。

| ファイル | 用途 | 状態 |
|---|---|---|
| `Ourin-0.2.0.zip` と `.sha256` | 本体。既存版の自動更新にも使用 | 署名・公証済みアプリを収録 |
| `Ourin-Installer-0.2.0.zip` と `.sha256` | 移行用インストーラー | 署名・公証済みアプリを収録 |
| `Ourin-0.2.0-booth.zip` と `.sha256` | 本体・インストーラー・説明・ライセンスをまとめたBOOTH用 | 署名・公証済みアプリを収録 |
| `Ourin-SHIORI-0.2.0.dmg` と `.sha256` | 新3種の `.plugin` とライセンス | 署名・公証済み |

追加3種は本体やBOOTH版のZIPに含めません。新3種のDMGを開き、必要な `.plugin` をOurinの導入画面で選択します。追加runtimeやHomebrewのインストールは不要です。CPU・最低OS条件は新3種ともmacOS 13.0以降のUniversal2です。

検証済みの全体は22パッケージ（実行用17・開発用サンプル5）ですが、今回の追加SHIORI配布は新3種だけです。Aosoraのローカル個人利用用や、再配布許諾の確認が済んでいないパッケージを一括公開するものではありません。

追加DMG: [Ourin-SHIORI-0.2.0.dmg](https://github.com/eightman999/Ourin/releases/download/v0.2.0-beta.1/Ourin-SHIORI-0.2.0.dmg)

新3種の開発版GUIでは導入・一覧表示・正常起動と、実キャラクターのダブルクリックから期待するSHIORI応答・スクリプト再生トークンまで確認しました。バルーン文字画像そのものは未取得です。これらは0.2.0最終コードの全体回帰や、署名・公証後の配布物の確認とは別の記録です。

## 制限

Windows専用DLL・SAORI・外部アプリ、任意のネイティブ拡張、すべての第三者ゴーストの互換性を保証するものではありません。Intel実機・最低対応macOSの実機での確認も残っています。

なし栞はmacOS移植版で、編集GUI「なしスタジオ」は含めません。source/package版は1.0.4-alpha系、SHIORIのversion応答は上流どおり `1.0.0` です。AYA5互換のversion応答は使用する公式YAYAの `Tc607-2` を保持します。
